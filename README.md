# Стационарный проигрыватель

Этот вариант создан на основе `Raspberry Pi Zero`, плате с очень скромными вычислительными возможностям, но которая, тем не менее, способна транслировать звук в высоком качестве через `bluetooth` (профиль `a2dp`). 

Первое, что нужно сделать для организации проигрывателя на базе такого одноплатника — правильно организовать файловое пространство. На флешке (`tf`-карте, или `microSD`) нудно выделить не только разделы `bootfs` и `rootfs`, но и раздел для музыки. Флешку нужно использовать большого объёма, чтобы на неё поместилась более-менее обширная музыкальная коллекция. Практика показывает, что 128-256 Мб вполне достаточно, хотя в наше время цены на такие носители настолько доступны, что можно выбрать и с запасом. В итоге должно получиться что-то такое:

```
sudo fdisk /dev/sdd -l                                                                                                                                                  
Disk /dev/sdd: 116,5 GiB, 125069950976 bytes, 244277248 sectors
Units: sectors of 1 * 512 = 512 bytes
Sector size (logical/physical): 512 bytes / 512 bytes
I/O size (minimum/optimal): 512 bytes / 512 bytes
Disklabel type: dos
Disk identifier: 0x5b557c61

Device         Boot    Start       End   Sectors   Size Id Type
/dev/sdd1          8192    532479    524288   256M  c W95 FAT32 (LBA)
/dev/sdd2        532480  16418664  15886185   7,6G 83 Linux
/dev/sdd3      16418816 244277247 227858432 108,7G  b W95 FAT32
```

Раздел с музыкой следует отформатировать так:

```
sudo mkfs.vfat -n MUSIC /dev/sdd3 
```

Это делает музыкальную коллекцию видимой не только в нашем проигрывателе, но и на устройствах с другими ОС (Windows) или даже на портативных колонках с microSD-слотом. 

Метка MUSIC нужна для монтирования. В файл /etc/fstab следует добавить строку:

```
LABEL=MUSIC           /var/lib/mpd/music vfat ro,uid=110        0       0
```

Таким образом, коллекция музыки монтируется в стандартную директорию плеера `mpd`, который в данном устройстве воспроизводит музыку.

В конфигурация `mpd` (`/etc/mpd.conf`) выглядит так:

```
music_directory         "/var/lib/mpd/music"
playlist_directory      "/var/lib/mpd/music"
db_file                 "/var/lib/mpd/tag_cache"
log_file                "/var/log/mpd/mpd.log"
pid_file                "/run/mpd/pid"
state_file              "/var/lib/mpd/state"
sticker_file            "/var/lib/mpd/sticker.sql"

user                    "mpd"
bind_to_address         "any"

input {
        plugin          "curl"
}

input {
        enabled         "no"
        plugin          "qobuz"
}

input {
        enabled         "no"
        plugin          "tidal"
}


decoder {
        plugin          "hybrid_dsd"
        enabled         "no"
}

filesystem_charset      "UTF-8"
audio_buffer_size       "8192"

audio_output {
        type "alsa"
        name "Колонки"
        device "bluealsa:DEV=11:22:33:44:55:66,PROFILE=a2dp"
        mixer_type "software"
}
```

Главное изменение по сравнению со стандартной — увеличен аудиобуфер и добавлено устройство вывода, представляющее собой аудиоколонку с `bluetooth`-подключением. Для соединения с ней нужно установить пакет `blue-alsa`, но, как будет показано в случае с портативным плеером, это не единственное решение.

Колонку следует подключить с помощью утилиты `bluetoothctl` (`pair...`, `trust...`). Далее она должна соединяться автоматически при загрузке проигрывателя. Точнее говоря, нужно сначала включить проигрыватель, а когда ОС закончит загрузку, включить колонку. Если всё сделано правильно, соединение должно установиться. Через несколько секунд из колонки должна раздаться музыка благодаря сервису `play-random`. Он дожидается подключения колонки, выбирает случайный плейлист с раздела с музыкой и начинает его проигрывать. Если до перезагрузки уже был запущен какой-то плейлист, то его воспроизведение продолжится с того места, на котором остановилось в предыдущий раз. 

Для управления проигрывателем я задействовал беспроводную клавиатуру, точнее говоря её правую часть с цифрами. Такие «обрубки» продаются отдельно и используются бухгалтерами. Поскольку этот вариант проигрывателя задумывался как стационарный, за особой компактностью я не гнался и смонтировал его  в корпусе старого картридера, что дало возможность подключить несколько `usb-устройств` (мощный `bluetooth-донгл` и адаптер беспроводной клавиатуры). На нажатия клавиш реагирует встроенный сервис triggerhappy, так что осталось только написать конфигурационный файл для него (`/etc/triggerhappy/triggers.d/90-keypad.conf`).
